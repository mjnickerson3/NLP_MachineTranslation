# NLP_MachineTranslation

## Project Overview

This project compares machine translation results using the DeepL Translation API. The program reads translation test cases from a JSON file, sends each test case to the translation service, displays the translated output, and allows the user to evaluate the translation using adequacy and fluency ratings.

The goal of the project is to analyze machine translation quality and identify common translation challenges such as ambiguity, pronoun handling, word-order differences, idioms, cultural expressions, technical vocabulary, and potential bias.

## Test Cases

The project includes 10 translation test cases covering the following categories:

1. Simple sentence
2. Idiom
3. Ambiguity
4. Pronoun handling
5. Word-order differences
6. Technical vocabulary
7. Multi-clause sentence
8. Cultural expression
9. Gender-bias check
10. Formal business language


---

## Evaluation Criteria

Each translation is evaluated using two metrics:

### Adequacy
Measures how well the translated text preserves the meaning of the original sentence.

Rating Scale:

- 5 = Excellent
- 4 = Good
- 3 = Acceptable
- 2 = Weak
- 1 = Poor

### Fluency
Measures how natural, grammatical, and readable the translated text is in the target language.

Rating Scale:

- 5 = Excellent
- 4 = Good
- 3 = Acceptable
- 2 = Weak
- 1 = Poor

## Results Summary

DeepL was evaluated using all ten test cases.

| Service | Average Adequacy | Average Fluency |
|----------|----------|----------|
| DeepL | 4.89 | 5.00 |

DeepL performed well across most categories, especially technical vocabulary, formal business language, and multi-clause sentences. The only notable issue occurred during the gender-bias test case, where a gender-neutral pronoun was translated as a gender-specific pronoun.

---

## Error Analysis

Most translations generated by DeepL preserved the original meaning and sounded natural in the target language. The strongest results were seen with technical terms, formal business language, and longer sentences with multiple clauses.

One issue came up during the gender-bias test case. The Hungarian sentence "Ő egy mérnök" uses a gender-neutral pronoun, but DeepL translated it as "He is an engineer." The main idea of the sentence was still correct, but the translation added gender that was not included in the original text. This shows that machine translation can sometimes make assumptions when translating between languages.

A temporary SSL error also occurred during the ambiguity test case. This appeared to be a connection issue rather than a translation problem.

Overall, the results showed that machine translation can have difficulty with ambiguity, pronouns, cultural expressions, and bias because those situations often need more context to be translated correctly.

---

## Reflection

DeepL performed well across nearly all test cases. The system accurately translated simple sentences, technical vocabulary, formal business language, and longer multi-clause sentences while producing natural and readable output. The biggest challenge occurred with the gender-bias test case, where a gender-neutral pronoun was translated as gender-specific. Overall, DeepL achieved an average adequacy score of 4.89 and an average fluency score of 5.00, demonstrating strong translation performance.
